# Understeer Modelling

Одностраничное веб-приложение-инфографика, показывающее, как возникает снос передней оси автомобиля: круг сцепления шины, силы в пятне контакта и насыщение шины при совмещении разгона/торможения с поворотом.

## Технологии

- Статический сайт без сборки: HTML + vanilla JS + SVG.
- Фреймворки и пакетные менеджеры не используются.
- Страница должна открываться напрямую из файловой системы (`file://`), поэтому ES-модули (`import`/`export`) не применяются — только обычные script-теги.
- Интерфейс двуязычный: английский (по умолчанию) и русский. Все строки — в словаре `I18N` внутри скрипта, статические элементы помечены `data-i18n` (статическая разметка — на английском, чтобы не мигало при загрузке), динамические строки — через `t()`. Выбор языка хранится в localStorage.

## Структура

- `index.html` — единственный файл приложения. По мере роста код можно выделять в `app.js` / `style.css`, подключая их обычными тегами.
- `favicon.png` — растровая иконка 32×32 для браузеров без поддержки SVG-фавиконок (Safari); SVG-вариант той же иконки встроен в `index.html` data-URI.

## Принятые решения

- Колесо на схеме одно и представляет всю переднюю ось.
- Скорость автомобиля задаётся ползунком 20–100 км/ч (по умолчанию 50).
- Коэффициент трения μ задаётся выбором поверхности: сухой асфальт 1,0 / мокрая дорога 0,6 / лёд 0,2.
- Ввод пользователя: газ (%), тормоз (%), угол поворота колёс.
- Темы оформления: тёмная (по умолчанию) и светлая; переключатель-иконка в шапке, выбор хранится в localStorage. Все цвета — CSS-переменные, динамические SVG-элементы получают цвета через классы.

## Физическая модель

Шина передаёт на дорогу суммарную силу, ограниченную кругом сцепления:

```
√(Fx² + Fy²) ≤ μ · Fz
```

- `Fx` — продольная сила: от педали газа (разгон) и тормоза, диапазоны 0…100% каждая, суммируются со знаком.
- `Fy` — боковая сила: потребность в повороте `Fy_потр = m · v² / R`, радиус `R = L / tan(δ)` из кинематической модели «велосипеда», `δ` — угол поворота колёс. Принятое допущение: передняя ось несёт долю боковой силы, равную доле нагрузки (`Fy_перед = доля · m · v² / R`), что эквивалентно согласованию жёсткости шин с развесовкой в установившемся повороте.
- Перенос веса: нагрузка на переднюю ось `Fz_дин = m · (доля·g + a_x·h / L)` при торможении и «−» при разгоне; `h = 0,5 м`. `a_x` выводится из силы на колесе: торможение — передняя ось даёт 70% усилия (`BIAS = 0.7`), разгон — передний привод (100%). Радиус круга динамический: `μ · Fz_дин`. Педали задают силу в ньютонах независимо от μ и масштабируются со статическим весом передней оси: 100% газа = 8 кН (`FX_GAS_MAX`), 100% тормоза = 12 кН (`FX_BRAKE_MAX`) при параметрах по умолчанию (значения по умолчанию `FZ_DEF`); фактическая сила дополнительно ограничена суммарным пределом сцепления (|a_x| ≤ μ·g, в пересчёте на переднюю ось — `BIAS·μ·m·g` при торможении).
- Блокировка колёс (ABS выключен, `SLIDE = 0.7`): если `|Fx_запр| > μ_ск · Fz_дин` (`μ_ск = 0.7·μ`), колесо скользит — фактическая `Fx = μ_ск · Fz_дин`, доступная боковая сила = 0, траектория полностью распрямляется. Симметрично для торможения (блокировка) и разгона (пробуксовка привода). При включённом ABS фактическая продольная сила ограничивается пределом `μ·Fz_дин` (антиблокировка/антипробуксовка), боковой остаётся остаток круга. Перенос веса уточняется итеративно по фактической `Fx` до сходимости (Fz_дин ↔ Fx взаимозависимы: Fx ограничена μ·Fz_дин, а Fz_дин зависит от a_x, который выводится из Fx). На круге сцепления при насыщении рисуется фактический вектор `(Fx, Fy_факт)`, а не масштабированный запрос.
- Параметры модели: скорость `v` и коэффициент трения `μ` задаются пользователем на основной панели; масса `m`, колёсная база `L`, высота CG `h` и доля нагрузки на переднюю ось `доля` — в раскрывающейся панели «Параметры модели» с заданными диапазонами (800–2500 кг, 2,0–3,5 м, 0,3–0,8 м, 45–65%) и кнопкой сброса к значениям по умолчанию (`DEF_*`). Полный набор текущих констант показывается строкой внутри той же панели (обновляется динамически); отдельный подвал со сводкой отсутствует.

Поведение при насыщении:

- `utilization = √(Fx² + Fy²) / (μ · Fz) ≤ 1` — сцепление есть, вектор скорости совпадает с направлением колёс (малый угол сноса). В блоке показаний `utilization` считается по запрошенной силе `Fx_запр` (видна глубина превышения предела педалью), а насыщение определяется по фактической `Fx`.
- `utilization > 1` — шина насыщена: доступная боковая сила падает до `Fy_дост = √((μ·Fz)² − Fx²)`, колесо проскальзывает, вектор скорости отклоняется от направления колеса (угол сноса), автомобиль недоповорачивает (understeer).

Направление движения при сносе (зелёная стрелка на схеме колеса):

- Шина выдаёт `Fy_факт = min(Fy_потр, Fy_дост)`, поэтому при насыщении радиус поворота растёт: `R_факт = (m · доля) · v² / Fy_факт` (при `Fy_факт = 0` радиус бесконечен — машина «плывёт» прямо).
- Вектор скорости отстаёт от направления колёс на угол сноса `α = δ − β`, где `β = atan(L / R_факт)` — угол направления движения, соответствующий реально достижимому радиусу. Сознательно выбрана геометрическая модель угла сноса, а не жёсткостная (`α = Fy / Cα` из линейной модели шины): она дидатически нагляднее и напрямую связывает снос с выходом за круг сцепления; жёсткостная модель — возможное развитие, см. `ROADMAP.md`.
- При `utilization ≤ 1` выполняется `β = δ`, `α = 0` — стрелки движения и колеса совпадают. Глубина сноса растёт с глубиной перенасыщения: чем сильнее запрос выходит за пределы круга, тем ближе направление движения к прямой, независимо от угла поворота колёс.
- Визуализация: при насыщении ободок колеса подсвечивается красным, за пятном контакта рисуется статичный след проскальзывания вдоль направления движения (вдоль зелёной стрелки). При выключенном ABS на оси Fx круга сцепления маркерами отмечены пороги блокировки/пробуксовки ±μ_ск·Fz_дин (маркер загорается красным при срыве), а превышение запрошенной силы над фактической показано пунктирным продолжением оранжевого вектора Fx.

Подробный план развития — в `ROADMAP.md`.
